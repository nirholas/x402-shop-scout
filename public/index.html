x402-shop-scout

Live marketplace intelligence over eBay Browse — listings search and is-this-a-deal verdicts. Every paid route answers an unpaid request with 402, then returns the purchased artifact in the body of the same request once you retry with an X-PAYMENT header.

OpenAPI · x402 manifest · health · source

Paid routes

RoutePriceReturns
GET /search $0.002 Live listings for a search term: price, shipping, condition, seller and item id.
GET /deal-check/:itemId $0.002 A verdict on one listing: its total cost against comparable listings, with the comparison set.

GET /health and GET /.well-known/x402 are free and unauthenticated.

Pay for one call

curl -s "$BASE/search?q=airpods%20pro"        # 402 + accepts[] (Base and Solana)
npx x402-fetch "$BASE/search?q=airpods%20pro"  # pays, retries, prints the listings

The 402 challenge carries the call schema for the route it guards (accepts[].outputSchema.input / .output), so an agent that has never read this page can still invoke the endpoint correctly.

Payment

  • USDC on Base (EIP-3009) or Solana (SPL transfer, facilitator-sponsored fees) — your wallet picks the rail.
  • Charged per request. No account, no API key, no subscription.
  • Settlement receipt returns in the X-PAYMENT-RESPONSE header and in the response body.
